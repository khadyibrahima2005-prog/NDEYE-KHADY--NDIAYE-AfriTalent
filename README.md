# AfriTalent
Projet fil rouge — Plateforme de mise en relation entre freelances africains et
clients.
Auteur : NDEYE KHADY NDIAYE
Promotion : L2 Web — ISI
## Description
AfriTalent est une plateforme qui permet aux entreprises de trouver des freelances qualifiés en Afrique.
Objectif du projet : créer un site vitrine 100% responsive avec dark/light mode.

## Fonctionnalités
- [x] Header fixe + menu burger mobile
- [x] Section Hero avec CTA
- [x] Affichage des catégories de freelances
- [x] Témoignages clients
- [x] Dark/Light mode avec localStorage
- [x] Footer 3 colonnes
- [x] Responsive Mobile / Tablette / Desktop
- [x]Compteurs animés
- [x]Animations au scroll

## Technologies utilisées
- *HTML5* : Structure sémantique
- *CSS3* : Flexbox, Grid, Media Queries
- *JavaScript* : Gestion du thème, menu burger
- *Bootstrap 5.3* : Grille et composants
